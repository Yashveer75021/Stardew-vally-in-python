# 🌾 Stardew Valley Inspired Game

A 2D top-down farming RPG inspired by Stardew Valley, built completely from scratch using **Python** and **Pygame**. 

This project features a fully functional farming system, day/night cycles, dynamic weather, an economy system, and a tile-based map setup.

## ✨ Features

* **Farming System:** Use your hoe to till the soil, plant seeds (corn, tomatoes), water them, and watch them grow over multiple days until they are ready to harvest.
* **Foraging & Resource Gathering:** Equip your axe to chop down trees, collect wood, and gather apples. Includes interactive particle effects!
* **Day/Night Cycle:** Go to sleep in your bed to transition between days, advance crop growth, and reset daily activities.
* **Dynamic Weather:** Randomized weather system. If it rains, your crops will be automatically watered for the day!
* **Economy & Merchant:** Open an interactive menu with the Trader to sell your harvested crops/foraged items and buy new seeds.
* **Tool & Seed Inventory:** Easily toggle between different tools (Axe, Hoe, Watering Can) and seeds.
* **Custom Camera & Depth (Y-Sorting):** A player-centered camera that gives a fake 3D depth effect (players can walk behind and in front of trees and buildings).
* **Tile-Based World Design:** The level is built using [Tiled](https://www.mapeditor.org/), allowing for highly modular and easily expandable world design.

## 🛠️ Technologies Used

* **Python 3.x**
* **[Pygame](https://www.pygame.org/)** - For the core game loop, logic, rendering, and sound mapping.
* **[PyTMX](https://github.com/bitcraft/PyTMX)** - To parse and load `.tmx` maps generated by Tiled.
